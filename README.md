# Proyecto de videojuego 2D en Unity

En este repositorio se encuentra todo el proyecto desarrollado en Unity, incluyendo las escenas, scripts, sonidos, animaciones, sprites y configuraciones utilizadas durante el desarrollo.

También se incluyeron las versiones finales del juego para poder probarlo sin necesidad de abrir Unity. El ejecutable para computadora está disponible en el repositorio y, adicionalmente, en la sección **Releases** se encuentran los archivos correspondientes tanto para Windows como para Android.

De esta manera, se puede revisar el proyecto completo desde el código fuente o descargar directamente una de las versiones compiladas para ejecutar el juego.
